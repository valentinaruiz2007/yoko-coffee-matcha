# YOKÓ — Coffee & Matcha · Proyecto 2 E2

Este proyecto Astro implementa el avance E2 del sitio web de marca de YOKÓ.

## Cómo ejecutar

1. Abre esta carpeta `yoko-e2` con VS Code.
2. Abre la terminal y ejecuta `npm install`.
3. Ejecuta `npm run dev` y abre la dirección indicada (normalmente http://localhost:4321).
4. Comprueba compilación con `npm run verificar`.

## Archivos principales

- `pack/`: tu plan original, brief, prompts, imágenes y tipografías.
- `src/components/inicio/`: componentes de portada, especialidades y bebidas.
- `src/pages/`: las cuatro rutas del mapa del sitio.
- `src/layouts/Base.astro`: encabezado, navegación y pie de página.
- `src/styles/global.css`: identidad visual de YOKÓ.
- `CAMBIOS.md`: cambios y asuntos pendientes.

## Nota

El plan original no define ciertos textos e imágenes específicos. Se dejan documentados en CAMBIOS.md. La fuente Cormorant Garamond debe incorporarse para que los títulos sean totalmente fieles al plan.
